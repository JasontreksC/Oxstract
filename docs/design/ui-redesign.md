# UI 개편 계획

작성일 2026-10-31. **확정됨(2026-10-31)**: [인터랙티브 목업](https://claude.ai/artifact/QcEmMAB1BkMQRtXEWGc9Dd) 방향으로 진행한다. 기능 쪽 계획은 [../roadmap.md](../roadmap.md). 지금 구현된 컴포넌트는 [components.md](components.md), 토큰은 [style-guide.md](style-guide.md)에 있다.

진행: 6장 1~5단계가 끝났다(골격, 대상 지정, 클립 타임라인, 스토리보드와 전환, 내보내기). 남은 것은 6단계 다듬기와 드라이브 링크. 3단계(클립 타임라인)도 끝났다: 움직임 그래프, 끌 수 있는 기준선, 구간 편집, 컷만 재생, 재생 중 추적 박스(M3~M4). 목업과 다른 점: 필름스트립 썸네일 줄은 아직 없고, 오른쪽 패널은 넓은 화면에서 뷰어 높이에 맞춰 안에서 스크롤한다(구간을 골라도 타임라인이 밀려나지 않게). 목업과 다른 점: "다음 클립에서도 같은 종류 자동 지정" 체크는 아직 없고, 분석 시작 버튼 대신 "이 대상으로 정하기"이고, 저장하면 분석이 뒤에서 바로 시작된다. 그래프는 목업의 이동·회전 두 줄에 내부 움직임을 더한 세 줄이다.

## 1. 지금 UI의 문제

| 문제 | 어디서 | 결과 |
|---|---|---|
| 상단 탭이 작업 순서와 상관없이 열림 | `App.tsx` 탭 | 영상도 없는데 타임라인에 가짜 구간이 보임 |
| 재생 바가 둘이고 서로 연결 안 됨 | `VideoPlayer` | 보이는 장면과 고른 시각이 다름 |
| 오버레이가 영상 컨트롤을 덮음 | `.overlay` | 재생·탐색을 못 함 |
| "드래그 / 탐지 박스" 모드 전환 | 선택 화면 | 왜 모드를 바꿔야 하는지 알기 어려움 |
| `0.05` 같은 날숫자 민감도 | 선택 화면 | 무엇의 0.05인지 알 수 없음. 결과를 보기 전에 정해야 함 |
| 진행 화면이 따로 있음 | 진행 탭 | 기다리는 동안 다른 일을 못 함 |
| 타임라인에 눈금, 재생 위치, 썸네일 없음 | `Timeline` | 어느 장면이 남는지 안 보임 |
| 전환 표시가 8px 막대이고 클릭 불가 | `Timeline` | 컷을 먼저 골라야 전환을 바꿀 수 있음 |
| 색을 `#RRGGBB` 텍스트로 입력 | 전환 패널 | 오타 나면 서버가 422 |
| 영상 하나만 다룸 | 전체 | 여러 영상을 이어 붙이는 핵심 흐름이 없음 |

## 2. 원칙

1. **한 화면, 순서가 보이는 단계.** 프로젝트 편집기 하나 안에서 상단 단계 표시(① 영상 ② 대상 ③ 구간 ④ 전환·텍스트 ⑤ 내보내기)로 지금 할 일을 알려 준다. 끝난 단계는 언제든 다시 열고, 아직 조건이 안 된 단계는 이유와 함께 비활성.
2. **기다리게 하지 않는다.** 분석과 렌더는 뒤에서 돌고, 진행률은 클립 카드와 상단 활동 표시에 나온다. 분석 중에도 다음 클립의 대상을 지정할 수 있다.
3. **숫자보다 결과를 보여 준다.** 민감도는 "낮음/보통/높음" 프리셋 + 움직임 그래프 위 임계선 끌기. 바꾸면 타임라인이 바로 바뀐다. 정확한 숫자는 "고급"에 접어 둔다.
4. **모드 없는 직접 조작.** 박스 클릭은 선택, 빈 곳 드래그는 직접 그리기. 전환 칩 클릭은 전환 설정. 구간 끝 끌기는 길이 조정.
5. **오른쪽 인스펙터 하나.** 무엇을 골랐는지에 따라 내용이 바뀐다(클립, 구간, 전환, 내보내기). 설정 패널이 화면 곳곳에 흩어지지 않는다.
6. **키보드.** Space 재생, ←/→ 한 프레임, Shift+←/→ 1초, I/O 구간 시작·끝, S 분할, Delete 구간 삭제, Ctrl+Z 되돌리기.

## 3. 화면 구조

### 3.1 홈: 프로젝트 목록

```text
+--------------------------------------------------------------------------+
| Oxstract                                              [설정]  [+ 새 프로젝트] |
+--------------------------------------------------------------------------+
|  +-------------+  +-------------+  +-------------+                        |
|  | [썸네일]     |  | [썸네일]     |  |             |                        |
|  | 주말 산책    |  | 강아지 놀이  |  |  + 새 프로젝트 |                        |
|  | 클립 3 · 1:42|  | 클립 1 · 렌더 |  |             |                        |
|  | 10월 29일   |  | 완료 ✓      |  |             |                        |
|  +-------------+  +-------------+  +-------------+                        |
+--------------------------------------------------------------------------+
```

프로젝트가 없으면 가운데에 큰 놓기 영역 하나: "영상을 끌어다 놓으면 새 프로젝트가 시작됩니다."

### 3.2 프로젝트 편집기 (공통 틀)

```text
+--------------------------------------------------------------------------+
| ← 주말 산책 ✎      ①영상 ── ②대상 ── ③구간 ── ④전환·텍스트 ── ⑤내보내기   ◔ 분석 1개 |
+-------------+------------------------------------------+-----------------+
| 클립         |                                          | 인스펙터         |
| ┌─────────┐ |                                          |                 |
| │▣ 1 walk │ |                 뷰어                      |  (선택한 것의    |
| │ ✓ 컷 4  │ |                                          |   설정)          |
| └─────────┘ |                                          |                 |
| ┌─────────┐ |                                          |                 |
| │▣ 2 park │ |                                          |                 |
| │ ◔ 62%   │ |                                          |                 |
| └─────────┘ |  ▶  00:12.40 / 01:05.00   [원본|컷만]     |                 |
| + 영상 추가  |                                          |                 |
+-------------+------------------------------------------+-----------------+
| 타임라인 (단계에 따라 클립 기준 또는 결과 기준)                              |
+--------------------------------------------------------------------------+
```

- 왼쪽 클립 목록: 썸네일, 이름, 길이, 상태 배지(대상 필요 / 분석 중 % / 컷 n개 / 오류). 끌어서 순서 변경. 결과 영상은 이 순서를 따른다.
- 가운데 뷰어: 재생 바는 하나뿐이고 타임라인의 재생 위치와 같은 값이다.
- 오른쪽 인스펙터: 폭 300px. 좁은 화면에서는 아래 서랍으로 내려간다.
- 상단 오른쪽 활동 표시: 돌고 있는 작업 수. 누르면 작업 목록과 취소 버튼.

### 3.3 ① 영상

- 빈 프로젝트는 뷰어 자리 전체가 놓기 영역. 여러 파일을 한꺼번에 받는다.
- 파일마다 업로드 진행 막대(XHR 진행 이벤트), 이어서 "미리보기 준비 중"(프록시 생성).
- 업로드가 끝난 클립을 누르면 바로 ② 대상으로 넘어간다.

### 3.4 ② 대상 지정

```text
뷰어
+------------------------------------------+
|        ┌──────────┐                      |
|        │ dog 0.91 │   ┌────────┐         |   ← 일시정지하면 탐지 박스가
|        │          │   │person  │         |      자동으로 뜬다 (점선)
|        └──────────┘   │ 0.84   │         |   ← 마우스를 올리면 실선 강조
|                       └────────┘         |   ← 빈 곳을 끌면 직접 그리기
+------------------------------------------+
 ▶ ━━━━━━━━━●━━━━━━━━━━━━━━  00:12.40

인스펙터
 대상
 ┌────────┐  dog · 신뢰도 0.91
 │ [크롭]  │  00:12.40 장면에서 선택
 └────────┘  [다시 고르기]

 [이 대상으로 분석 시작]   ← 주 버튼 하나

 □ 다음 클립에서도 같은 종류 자동 지정
```

- 재생 중에는 박스가 없다. 멈추는 순간 그 시각의 서버 프레임으로 바꾸고 탐지를 부른다(0.3초 디바운스, 응답 전에는 "탐지 중" 작은 표시).
- 탐지 박스가 없거나 원하는 물체가 목록에 없으면 안내: "원하는 물체를 직접 드래그하세요."
- 분석 시작을 누르면 클립 카드가 "분석 중"으로 바뀌고, 다음 대상이 필요한 클립으로 자동 이동한다.

```text
타임라인
 0s        10s        20s        30s        40s        50s       1:05
 |----------|----------|----------|----------|----------|----------|
 [필름스트립 썸네일 ─────────────────────────────────────────────────]
  움직임  ╱╲      ╱╲╱╲╲                ╱╲         ╱╲╱╲
 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ ← 임계선 (끌어서 조정)
 ▓▓▓▓▓▓░░░░░▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░▓▓▓▓░░░░░░░░▓▓▓▓▓▓▓░░░
   컷1          컷2                     컷3          컷4
                 ▲ 재생 위치
```

- 위에서부터 눈금, 썸네일 띠, 움직임 그래프(이동·회전 합성 값, 범례로 각각 켜고 끔), 남는 구간 띠.
- 남는 구간은 강조색, 버려지는 부분은 어둡게. 구간 양끝을 끌면 길이 조정, 빈 곳을 끌면 새 구간, 구간을 누르면 인스펙터에 시작·끝 시각과 삭제·분할.
- 뷰어의 [원본 | 컷만] 전환으로 남는 부분만 이어 보기.
- 인스펙터(클립 선택 시):

```text
 민감도   [ 낮음 | 보통 | 높음 ]
 움직임 기준  ☑ 이동  ☑ 회전
 컷 사이 짧은 멈춤 합치기  ────●──  0.5초
 컷 앞뒤 여유              ──●────  0.3초
 ▸ 고급 (이동·회전 임계값, 최소 컷 길이)

 결과: 컷 4개 · 18.2초 (원본 1:05의 28%)
 [자동 구간으로 되돌리기]
```

- 손으로 고친 구간에는 작은 연필 표시. 민감도를 바꿔도 그 구간은 유지되고, "자동 구간으로 되돌리기"로만 지워진다.

### 3.6 ④ 전환·텍스트 (결과 기준 스토리보드)

```text
타임라인 (결과 순서)
 ┌──────┐   ┌──────┐   ┌──────┐ ║ ┌──────┐   ┌──────┐
 │ 1-1  │ ◆ │ 1-2  │ ▣ │ 1-3  │ ║ │ 2-1  │ · │ 2-2  │      ← 클립 경계는 ║
 │ 3.2s │   │ 4.0s │   │ 2.1s │ ║ │ 5.5s │   │ 3.4s │
 └──────┘   └──────┘   └──────┘ ║ └──────┘   └──────┘
           페이드    텍스트          없음
 [+ 시작 제목]                                     [+ 끝 제목]   총 18.2초
```

- 컷은 대표 썸네일과 길이. 컷 사이의 칩(◆ 페이드, ▣ 텍스트 카드, · 없음)을 누르면 인스펙터가 전환 설정으로 바뀐다.
- 인스펙터(전환 선택 시):

```text
 전환  [ 없음 | 페이드 | 텍스트 카드 ]

 (텍스트 카드)
 ┌──────────────────────────┐
 │       다음 장면            │  ← 실제 비율의 미리보기
 └──────────────────────────┘
 문구      [다음 장면           ]
 배경      [■ #111111]  글자 [■ #FFFFFF]   ← 색 고르기 팝오버 + 견본
 글자 크기  ───●────  48
 표시 시간  ──●─────  2.0초

 [모든 컷 사이에 적용]
```

- 시작·끝 제목 카드는 텍스트 카드와 같은 편집기를 쓴다.
- 칩 위에 마우스를 올리면 앞뒤 1초를 이어 붙인 짧은 미리보기를 뷰어에서 재생한다(브라우저에서 CSS 페이드와 오버레이로 흉내, 실제 렌더 아님).

- 끝나면 뷰어에서 결과를 바로 재생.

## 4. 시각 스타일

- 어두운 테마는 유지한다(영상 색을 해치지 않음). 대신 테두리를 줄이고 면의 밝기 차이로 영역을 나눈다: 배경 `#0e1116`, 패널 `#151a21`, 띄운 요소 `#1d232c`. 테두리는 입력과 구분이 꼭 필요한 곳에만.
- 강조색은 파랑 하나만 주 동작·선택·재생 위치에 쓴다. 상태 색(초록 완료, 호박 주의, 빨강 오류)은 배지와 아이콘에만.
- 타임라인 색: 남는 구간 = 강조색 60% 채움, 버려지는 부분 = 30% 어둡게, 움직임 그래프 = 밝은 회청색 선, 임계선 = 호박색 점선, 페이드 칩 = 보라, 텍스트 칩 = 호박.
- Pretendard를 npm 패키지(`pretendard`)로 번들에 포함해 오프라인에서도 같은 글꼴이 나오게 한다. 지금은 설치된 컴퓨터에서만 의도대로 보인다.
- 아이콘은 `lucide-react`. 아이콘만 있는 버튼에는 툴팁과 `aria-label`.
- 숫자 시각은 고정폭 숫자(`font-variant-numeric: tabular-nums`)로 `mm:ss.cc` 표기.
- 최소 폭 1280px에서 3단, 1024px 이하는 인스펙터가 아래 서랍, 768px 이하는 클립 목록이 상단 가로 띠.

## 5. 프론트 구조

| 영역 | 선택 | 이유 |
|---|---|---|
| 라우팅 | `react-router` | `/`, `/p/:projectId/:step` 로 새로고침해도 같은 화면 |
| 서버 상태 | `@tanstack/react-query` | 프로젝트, 클립, 구간 조회와 캐시, 낙관적 갱신 |
| 편집 상태 | `zustand` | 선택한 것, 재생 위치, 되돌리기 스택 |
| 접근성 있는 기본 부품 | Radix(`slider`, `toggle-group`, `popover`, `dialog`, `tooltip`) | 키보드와 스크린리더 지원을 직접 만들지 않음 |
| 순서 변경 | `@dnd-kit/sortable` | 클립 목록 끌기 |
| 타임라인 그리기 | `<canvas>` 1장 + DOM 핸들 | 긴 영상의 그래프·썸네일을 가볍게 |
| 스타일 | 지금의 CSS 토큰 + CSS Modules | 토큰 체계를 그대로 살림 |

```text
    sequence/   Storyboard, TransitionChip, TransitionInspector
    export/     ExportInspector, RenderHistory
  player/       Viewer(단일 video 요소, 컷만 재생 로직), useFrameStep
  ui/           Button, Segmented, Slider, ColorField, Badge, Toast, Empty
  store/        editor.ts (zustand)
  styles/       tokens.css, tokens.ts
```

좌표 규칙: 서버와 주고받는 bbox는 항상 원본 픽셀. 화면 변환은 `player/` 안 한 함수(`stageToSource`, `sourceToStage`)에서만 하고, 레터박스 여백과 회전 메타데이터를 처리한다.

## 6. 진행 순서

기능 마일스톤([roadmap.md](../roadmap.md) 4장)과 맞물린다.

1. **골격** (M1.5와 함께): 라우팅, API 클라이언트, 편집기 3단 틀, 단계 표시, 클립 목록과 업로드. 가짜 데이터를 전부 지운다.
2. **뷰어와 대상 지정** (M2): 단일 재생 바, 프레임 이동 단축키, 정지 프레임 위 박스 선택, 좌표 변환 테스트.
3. **클립 타임라인** (M3~M4): 눈금, 썸네일 띠, 움직임 그래프, 임계선, 구간 편집, 컷만 재생.
4. **스토리보드와 전환** (M5): 전환 칩, 텍스트 카드 편집기와 미리보기, 시작·끝 제목.
5. **내보내기와 활동 표시** (M5~M7): 렌더 설정, 진행, 이력, 드라이브 링크, 토스트.
6. **다듬기**: 빈 상태 문구, 오류 문구, 반응형, 키보드 도움말(`?`).
